# Огород v2.0 - Система управления поливом на ESP32

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: ESP32](https://img.shields.io/badge/Platform-ESP32-blue.svg)](https://www.espressif.com/en/products/socs/esp32)
[![Framework: Arduino](https://img.shields.io/badge/Framework-Arduino-green.svg)](https://www.arduino.cc/)

Система автоматического управления поливом для теплицы и огорода с управлением через Telegram, веб-интерфейс GyverHub и MQTT.

## 📋 Возможности

- **6 режимов работы:**
  - Полив теплицы (по таймеру)
  - Капельный полив (по таймеру)
  - Спринклерный полив (3 направления)
  - Автоналив бака (поддержание уровня)
  - Фитолампа (по таймеру)
  - Управление фрамугой (по температуре)

- **Датчики:**
  - Уровень воды в баке (ультразвуковой)
  - 2x датчика потока YF-S201 (полив/налив)
  - Температура и влажность воздуха (DHT11)
  - Влажность почвы (цифровой + аналоговый)
  - Температура почвы (DS18B20)

- **Управление:**
  - LCD1602 дисплей с кнопками
  - Telegram бот
  - Веб-интерфейс GyverHub
  - MQTT для интеграции

- **Защиты:**
  - Отключение насоса при низком уровне бака
  - Контроль потока (отключение при отсутствии воды)
  - Запрет полива при сухой почве

## 🔧 Установка

### 1. Подготовка Arduino IDE

1. Установите [Arduino IDE](https://www.arduino.cc/en/software)
2. Добавьте плату ESP32:
   - Файл → Настройки → Дополнительные ссылки для менеджера плат:
     ```
     https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
     ```
   - Инструменты → Платы → Менеджер плат → Найдите "ESP32" → Установите

3. Установите библиотеки (через Менеджер библиотек):
   - `GyverHub`
   - `GyverNTP`
   - `FastBot2`
   - `FlowSensor`
   - `DHT` (Adafruit или Gyver)
   - `LiquidCrystal_I2C`
   - `RCSwitch`

### 2. Настройка скетча

Откройте `sketch_akt_new_teplica_esp32_lcd_rus_klap.ino` и измените:

```cpp
#define AP_SSID "YOUR_WIFI_SSID"      // Ваш WiFi
#define AP_PASS "YOUR_WIFI_PASSWORD"  // Ваш пароль
#define BOT_TOKEN "YOUR_BOT_TOKEN"    // Токен Telegram бота
#define CHAT_ID "YOUR_CHAT_ID"        // Ваш Chat ID
```

### 3. Загрузка

1. Подключите ESP32 к компьютеру
2. Выберите плату: Инструменты → Плата → ESP32 → ESP32 Dev Module
3. Выберите порт
4. Нажмите Загрузить

## 📱 Использование

### Кнопки на устройстве

| Действие | Кнопка ВЫБОР | Кнопка ПОДТВЕРЖДЕНИЕ |
|----------|--------------|----------------------|
| Короткое | Переключение режима | Подтверждение выбора |
| Долгое (>1.5с) | Вход в меню | Показать уровень бака |

### Telegram бот

Отправьте `/start` вашему боту для получения меню управления.

### GyverHub

1. Откройте [GyverHub](https://gyverhub.ru/)
2. Найдите устройство "Ogorod_esp32"
3. Управляйте режимами и настройками

## 📊 MQTT топик

| Топик | Описание |
|-------|----------|
| `tank` | Уровень бака (100-cm) |
| `pot_poliv` | Поток полив (л/мин) |
| `pot_naliv` | Поток налив (л/мин) |
| `tempr` | Температура воздуха |
| `humid` | Влажность воздуха |
| `disp_3` | Температура почвы |

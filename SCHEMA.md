# Схема подключения "Огород v2.0"

## Оборудование
- ESP32 DevKit v1
- LCD1602 с модулем I2C (адрес 0x27)
- TCA9555 (I2C расширитель портов)
- 8-канальный релейный модуль 5В с оптопарой
- Датчик уровня воды (ультразвуковой)
- 2x датчика потока YF-S201
- DHT11 (температура/влажность воздуха)
- Датчик влажности почвы (цифровой + аналоговый)
- Датчик температуры почвы (опционально DS18B20)
- 2 кнопки (нормально разомкнутые)
- RF передатчик 433MHz

## Подключение TCA9555 к релейному модулю

TCA9555 имеет 16 выходов (Port 0: P00-P07, Port 1: P08-P15).
Используем Port 0 (P00-P07) для 8-канального реле:

| TCA9555 | Реле канал | Устройство              |
|---------|------------|-------------------------|
| P00     | Канал 1    | Насос                   |
| P01     | Канал 2    | Клапан теплицы          |
| P02     | Канал 3    | Клапан капельного полива|
| P03     | Канал 4    | Клапан 1 направления    |
| P04     | Канал 5    | Клапан 2 направления    |
| P05     | Канал 6    | Клапан 3 направления    |
| P06     | Канал 7    | Подача фазы (10 сек)    |
| P07     | Канал 8    | Фрамуга                 |

**Важно:** Релейный модуль с оптопарой требует отдельного питания 5В!
- VCC реле -> 5В внешний блок питания
- GND реле -> GND общий с ESP32
- IN1-IN8 -> P00-P07 TCA9555

## Подключение реле на плате ESP32

Два дополнительных реле подключены напрямую к GPIO:

| GPIO | Устройство        | Назначение            |
|------|-------------------|-----------------------|
| 26   | Реле 1            | Фитолампа             |
| 2    | Реле 2            | Клапан налива бака    |

**Примечание:** GPIO 2 должен быть свободным во время загрузки ESP32.
Если возникают проблемы с загрузкой, используйте GPIO 12 или 13 вместо GPIO 2.

## Датчики потока YF-S201

### Датчик ПОЛИВ (manPin = GPIO 27)
- Красный провод (VCC) -> 5V
- Черный провод (GND) -> GND
- Желтый провод (SIGNAL) -> GPIO 27 через подтяжку 10к к 5V

### Датчик НАЛИВ (fillPin = GPIO 14)
- Красный провод (VCC) -> 5V
- Черный провод (GND) -> GND
- Желтый провод (SIGNAL) -> GPIO 14 через подтяжку 10к к 5V

## Кнопки управления

### Кнопка ВЫБОР РЕЖИМА (btnModePin = GPIO 33)
- Один контакт -> GPIO 33
- Второй контакт -> GND
- Подтяжка INPUT_PULLUP внутренняя

### Кнопка ПОДТВЕРЖДЕНИЕ (btnConfirmPin = GPIO 25)
- Один контакт -> GPIO 25
- Второй контакт -> GND
- Подтяжка INPUT_PULLUP внутренняя

## Логика работы кнопок

| Действие              | Кнопка ВЫБОР       | Кнопка ПОДТВЕРЖДЕНИЕ |
|-----------------------|--------------------|-----------------------|
| Короткое нажатие      | Переключение режима| Подтверждение выбора  |
| Долгое нажатие (>1.5с)| Вход в меню        | Показать уровень бака |

## Режимы работы (переключаются по кругу)

0. **Полив теплицы** - включение клапана теплицы по таймеру
1. **Капельный полив** - включение клапана капельного + насос
2. **Спринклерный полив** - 3 направления + насос
3. **Автоналив** - поддержание уровня в баке
4. **Фитолампа** - освещение по таймеру
5. **Фрамуга** - вентиляция по температуре

## Аварийные защиты

1. **Низкий уровень бака** (cm < 18): запрет включения насоса
2. **Нет потока** (через 3 сек после включения насоса): отключение насоса
3. **Влажность почвы** (k == 1): запрет полива

## Настройка таймеров

В коде установлены значения по умолчанию:
- `y_greenhouse = 6` - теплица в 06:00
- `y_drip = 7` - капельный в 07:00
- `y_sprinkler = 8` - спринклер в 08:00
- `y_phylamp = 18` - фитолампа в 18:00

Длительность:
- `duration_greenhouse = 30` - теплица 30 мин
- `duration_drip = 10` - капельный 10 мин
- `duration_sprinkler = 15` - спринклер 15 мин

## MQTT топик для отправки данных

- `tank` - уровень бака (100-cm)
- `pot_poliv` - поток полив (л/мин)
- `pot_naliv` - поток налив (л/мин)
- `tempr` - температура воздуха
- `humid` - влажность воздуха
- `disp_3` - температура почвы
- `disp_1` - влажность почвы (цифровой)
- `disp_2` - влажность почвы (ADC)

# Изменения в скетче "Огород v2.0"

## Выполненные требования

### 1. Библиотека GyverHub
- Сохранены все объекты GyverHub
- Добавлены новые виджеты:
  - LED индикаторы состояния 6 режимов
  - Виджеты двух датчиков потока (полив/налив)
  - Виджет температуры почвы
  - Виджеты настройки времени для 4 таймеров
  - Аварийные индикаторы (уровень/поток)

### 2. Удалено управление выходами
**Удалены:**
```cpp
#define UPR_1 32  // насос
#define UPR_2 33  // клапан капельный
#define UPR_3 25  // клапан разбрызгиватель
#define UPR_4 26  // клапан теплица
#define ZAKR 14   // закрытие клапанов
```

**Добавлен I2C модуль TCA9555:**
- Адрес: 0x20 (A0-A3 на GND)
- 8 выходов P00-P07 для релейного модуля

### 3. Схема подключения TCA9555

| Выход TCA9555 | Устройство              |
|---------------|-------------------------|
| P00           | Насос                   |
| P01           | Клапан теплицы          |
| P02           | Клапан капельного полива|
| P03           | Клапан 1 направления    |
| P04           | Клапан 2 направления    |
| P05           | Клапан 3 направления    |
| P06           | Подача фазы (10 сек)    |
| P07           | Фрамуга                 |

### 4. Добавлены кнопки
- **btnModePin (GPIO 33)** - выбор режима
- **btnConfirmPin (GPIO 25)** - подтверждение

**Логика:**
- Короткое нажатие: переключение режима / подтверждение
- Долгое нажатие (>1.5с): вход в меню / показать уровень бака

### 5. Уровень бака на LCD
- Горизонтальная шкала в нижнем ряду
- Слово "УРОВЕНЬ" в верхнем ряду
- Отображение при удержании кнопки подтверждения

### 6. Датчик потока полив
- Пин: `manPin 27` (YF-S201)
- Проверка потока через 3 сек после включения насоса

### 7. Датчик потока налив
- Пин: `fillPin 14` (YF-S201)
- Отдельный виджет в GyverHub

### 8. Датчик температуры почвы
- Пин: `soilTempPin 32`
- Виджет в GyverHub и MQTT

### 9. Запрет полива при влажности почвы
```cpp
if (k == 1) return;  // k==1 means сухо
```

### 10. Три таймера для режимов
- `y_greenhouse` - теплица (часы)
- `y_drip` - капельный (часы)
- `y_sprinkler` - спринклер (часы)
- `y_phylamp` - фитолампа (часы)

### 11. Запрет насоса при низком уровне
```cpp
if (cm < 18) return;  // cm < 18 = уровень ниже 18 см
```

### 12. Выключение насоса при отсутствии потока
```cpp
if (millis() - flowCheckTime >= 3000 && !flowDetected) {
  if (d_poliv < 0.5) {
    // Нет потока - выключить насос
  }
}
```

## Режимы работы

| № | Режим          | LCD отображение   | Логика                                    |
|---|----------------|-------------------|-------------------------------------------|
| 0 | Теплица        | "полив теплицы"   | Клапан теплицы 30 мин + фаза 10 сек       |
| 1 | Капельный      | "капельный полив" | Клапан 10 сек + насос 10 мин + фаза       |
| 2 | Спринклер      | "спринклер N напр"| 3 направления, каждое: 10 сек + насос 5 мин|
| 3 | Автоналив      | "автоналив"       | Вкл при cm>75, выкл при cm<=20            |
| 4 | Фитолампа      | "фитолампа"       | Вкл на 4 часа по таймеру                  |
| 5 | Фрамуга        | "фрамуга откр"    | Вкл при t>35, выкл при t<=20              |

## MQTT топик для передачи данных

- `tank` - уровень бака (100-cm)
- `pot_poliv` - поток полив (л/мин)
- `pot_naliv` - поток налив (л/мин)
- `tempr` - температура воздуха
- `humid` - влажность воздуха
- `disp_3` - температура почвы
- `disp_1` - влажность почвы (цифровой)
- `disp_2` - влажность почвы (ADC)
- `ld_greenhouse` - статус режима теплицы
- `ld_drip` - статус режима капельный
- `ld_sprinkler` - статус режима спринклер
- `ld_fill` - статус режима автоналив
- `ld_phylamp` - статус режима фитолампы
- `ld_framuga` - статус режима фрамуги
